## 资源预算实测（`make bench`，回环夹具在独立进程）

| 预算（`04-delivery-validation.md` §6） | 实测 | 结论 |
| --- | --- | --- |
| 持续创建/关闭 100 次会话后 goroutine、文件描述符回到基线 | 100 次完整 SSH 握手 + 终端开关；goroutine 5 → 5，文件描述符 9 → 9 | 通过 |
| 连续输出 100 MiB 时内存不随累计输出线性增长 | 100 MiB 经 SSH → 有界流缓存 → 消费确认，用时 70 ms；进程堆峰值 3.8 MiB | 通过 |
| 上传 1 GiB 使用流式处理，内存不出现同量级增长 | 1024 MiB 经 SFTP 上传，用时 1.8 s（563 MiB/s）；进程堆峰值 3.9 MiB | 通过 |

说明：吞吐数字只代表本机回环与当前硬件，不是网络环境下的承诺。`pkg/sftp` 自带的内存文件系统会对每个写入字节刻意休眠 1 µs 并把内容留在内存中，因此大文件基准把上传写入夹具的 `/discard/` 目录（接收并丢弃字节），只度量本应用的上传路径；首次尝试直接写入内存文件系统时，1 GiB 用时约 19 分钟，这是夹具限制而不是应用行为。

## 过程中发现并修正的问题

独立代码审阅（只读、未参与实现）发现并已修正、均有回归测试或复现确认：

- **高**：x/crypto/ssh 在每次重新协商密钥时都会再次调用主机密钥回调，而回调沿用了连接完成后即被取消的拨号上下文，导致任何连接在首次 re-key（chacha20 约 1 GiB 流量，或服务器按时间 re-key）时被断开。现改为首次验证后在本连接内固定该密钥，后续只比对字节、不查库也不询问；新增“每 4 KiB re-key 的服务器上取消拨号上下文后仍收齐 256 KiB”的回归测试，并确认去掉修复时该测试失败。
- **中**：连接租约在拨号中被并发关闭时存在数据竞争与客户端泄漏 → 资源登记加锁，关闭后到达的资源立即关闭；新增握手中取消的 race 测试。
- **中（Windows）**：命名管道名可预测，可能被其他本机账户抢注 → CLI 与服务在使用前核对管道服务进程的用户 SID，且 CLI 只打开 `http://127.0.0.1:` 链接。
- **中**：远端保存时临时文件在 chmod 前以服务器默认权限存在 → 先建 0700 私有暂存目录，在其中写入后再原子改名；集成测试确认不残留暂存目录。
- **低**：递归删除与文件夹上传在每次删除/创建前复查父目录仍是真实目录（SFTP 无 *at 调用，窗口只能缩小不能消除）；交互式认证主机复用终端连接的 SFTP 通道现可被取消；密码认证的 keyboard-interactive 只回答普通 “Password:” 提示且每连接一次（不再把账户密码填给一次性验证码提示）；日志脱敏覆盖结构体、字节切片与 LogValuer；远程登录记录表满时淘汰最旧记录而不是拒绝所有人；取消与成功竞争时释放已建立的终端/隧道；本机文档并发保存串行化；凭据库头部的 Argon2 参数设上限。

- 在已打开工作台的浏览器中运行 `sshworkbench edit/open` 会创建新会话并覆盖 Cookie，使原标签页写操作 403、终端失联。现改为：浏览器已有有效会话时只消耗一次性令牌并加入该会话（有回归测试）。
- 模态框未居中（Tailwind v4 基础样式清除了 `<dialog>` 的 `margin`）；提示在打开的对话框下被遮挡（改为顶层 popover）。
- 主机搜索的快捷键提示写死为 ⌘K，现显示实际绑定。
- E2E 中的合成 IME 步骤最初不稳定：根因是测试工具（`insertText` 不产生按键、弹窗关闭后页面不在前台、按键与 CDP 组合交错），在裸 xterm.js 页面复现确认不是应用缺陷；已改用真实按键并等待回显。

## 不能据此声称通过

- macOS 系统拼音/Rime、Windows 微软拼音、Linux Fcitx5/IBus 的真实 composition 验收。E2E 的 IME 步骤使用 Chrome DevTools 协议合成组合事件，只是回归补充，**不证明任何真实输入法正确**。
- 与旧工程、Keyway/Termix 在同机同输入法下的对照（M0 门槛）。
- Windows/Linux 真机完整工作流（包括 Windows 命名管道 ACL、OpenSSH agent pipe、系统凭据管理器），Safari/Firefox，手机虚拟键盘。
- 真实 OpenSSH 各版本、不同 SFTP 服务端实现（夹具的内存 SFTP 忽略 chmod 位，因此 chmod 只验证了请求与校验路径）、生产服务器负载与权限差异、非回环网络下的吞吐与背压。
- 互联网暴露场景的独立渗透测试或正式安全审计；读屏软件等完整无障碍实测。

夹具执行真实 SSH 握手、keyboard-interactive、direct-tcpip 与 SFTP 协议，但 shell 是受控回显程序，不能代替 Vim/tmux/远端 locale 的真实环境测试。
