## 已实现

- **运行形态**：Go 模块化单体，React 19 / TypeScript / Vite / Tailwind 界面离线内嵌；无运行时 Node、Wails、Electron 或 CDN。
- **授权**：本机一次性浏览器授权（可通过 `sshworkbench open` 在不重启服务的情况下申请新链接）、精确 Host/Origin、CSRF、HttpOnly 会话；远程模式使用所有者密码与直接 TLS。注销/过期会结束该登录的连接尝试、终端、隧道并锁定凭据库。
- **本机控制通道**：数据目录内 0600 Unix socket / 仅当前用户 SID 的 Windows 命名管道；只支持 `open` 与 `edit`。重复启动会转为向已运行实例申请授权。
- **主机**：分组、收藏、最近使用、搜索、编辑/删除、生产标记；被跳板或隧道引用的主机不能删除。
- **OpenSSH 配置导入**：本机 `~/.ssh/config`（Include 限 `~/.ssh` 真实路径、深度 5、32 文件、防循环）或粘贴/上传文本（不跟随 Include）；支持 Host/HostName/User/Port/IdentityFile/IdentitiesOnly/IdentityAgent/单级 ProxyJump；ProxyCommand/LocalCommand/RemoteCommand/Match exec 不执行且相关主机不导入；其他不支持指令逐项诊断。导入只创建配置，不信任任何主机密钥。
- **认证**：密码（含 PAM 风格的单问题 keyboard-interactive 自动作答）、私钥与口令（浏览器选择，或本机模式下 `~/.ssh` 内路径由服务端读取）、系统 agent（不转发）、keyboard-interactive/MFA（逐轮把服务器问题交给用户）。
- **主机身份**：每一跳在握手内作为 prompt 交给发起者确认；本机模式附带只读的 `~/.ssh/known_hosts` 比对提示；已知密钥变化与信任存储故障失败关闭；后台重拨不能接受新密钥。
- **单级跳板**：跳板与目标分别认证、分别核对；嵌套跳板在保存时拒绝。
- **凭据库（可选）**：默认凭据只在内存；用户可在连接成功后保存，或在设置中添加。XChaCha20-Poly1305 + 随机数据密钥；系统凭据存储或 Argon2id 主密码保护；错误 5 次锁 1 分钟；浏览器只看到名称；重置会永久删除全部密文。
- **终端**：多标签（拖动排序，键盘可操作）、单屏/左右/上下/四宫格可调分屏、布局与偏好持久化（刷新后以“未连接”占位恢复）、搜索、主题、字号/滚动/光标、可配置快捷键（不在 IME 组合期间触发，也不会同时输入到 Shell）、退出码/信号显示、二进制输入输出、背压、同页短断重连与超时回收。
- **文件**：独立 SSH transport 上的 SFTP（交互式认证主机改用终端连接上的 SFTP channel）；列表、排序、隐藏文件、目录导航、新建目录、重命名、chmod、删除（目录递归删除前统计并要求服务端再次清点一致）、复制远端路径、单文件下载、文件夹 zip 打包下载（跳过符号链接，≤10,000 项、≤4 GiB）。
- **上传**：明确目标目录的多文件与文件夹上传队列（拖拽或选择），最多并发 2 个、每文件 ≤1 GiB、≤10,000 项、≤32 层；中间目录必须是真目录；排他创建拒绝覆盖；上传中关闭页面会提示。
- **编辑器**：懒加载的本地 Monaco；远端文件与 `sshworkbench edit` 登记的本机文件共用规则：UTF-8/BOM、LF/CRLF、2 MiB、内容+元数据版本检查、临时文件后原子替换；混合换行只读；新浏览器窗口。
- **隧道**：`-L` 本地转发，只监听 127.0.0.1 / ::1；先绑定端口（占用立即报错）再建立独立 SSH 连接；状态、活动/累计连接数、收发字节；停止、编辑、删除；SSH 断开即停止并显示原因；不随终端标签关闭。
- **命令片段与广播**：片段库；插入（不回车）或确认后执行；多主机整条命令广播——显式勾选目标、预览、输入目标数量确认、逐台“已发送/未发送”结果，不重试不补发。
- **Shell 目录跟随**：接受与主机匹配的 OSC 7；设置中提供 Bash/Zsh 片段供用户自行添加，应用不修改远端 rc 文件、不注入命令。
- **契约与发布**：REST 契约生成 Go DTO 与 TS 类型并检查漂移；WebSocket 单独版本化；`make dist` 交叉编译 5 个平台并生成 SHA256SUMS；`.goreleaser.yaml`；`THIRD_PARTY_NOTICES.md` 由脚本生成。

## 当前边界

| 项目 | 当前行为 |
| --- | --- |
| 终端恢复 | 同页短断恢复；整页刷新恢复布局占位，不恢复旧屏幕，不假装重建相同 shell |
| 交互式认证主机的文件操作 | 复用终端已认证的连接开 SFTP channel；终端断开后需重新连接，文件操作不会自行再次询问 MFA |
| 隧道重连 | SSH 断开后停止并标记失败，不自动重连（可能需要再次 MFA）；需手动重新启动 |
| 上传原子性 | 排他创建防覆盖，但上传期间文件可见；取消/掉线可能留有不完整文件；没有断点续传 |
| 保存并发 | 前后两次版本检查 + rename，不是跨客户端 CAS；远端保存先写入 0700 私有暂存目录（服务器若忽略 chmod 则保护失效） |
| 远端符号链接竞争 | 递归删除与文件夹上传在每步前复查父目录，但 SFTP 没有 *at 调用，其他账户在两次调用之间替换目录的窗口只能缩小，不能消除；不要对他人可写的目录树做递归删除 |
| 会话中的主机密钥 | 首次验证后在该连接内固定；re-key 时密钥变化即断开 |
| 文件元数据 | 保留基本权限（远端另尝试 UID/GID）；不保证 ACL、xattr、硬链接 |
| 路径 | 远端按 POSIX 处理；非 UTF-8 名称不可操作，且会让目录树操作整体停止；符号链接不打开、不跟随 |
| 系统 agent | 本机默认可用；远程模式默认关闭（`--allow-agent`）。Windows 使用 OpenSSH agent pipe，不支持 Pageant |
| 本机文件 | 仅本机模式：`~/.ssh` 内私钥、`~/.ssh/config`、`~/.ssh/known_hosts`（只读提示）与 CLI 登记的文本文件；远程模式全部关闭 |
| 凭据库锁定 | 系统凭据存储模式下“锁定”只清除内存中的密钥，下次使用会自动从系统存储读取 |
| 远程部署 | 只支持 Go 直接终止 TLS；不接受 forwarded headers |
| 密码重置 | 停止服务后运行 password 子命令再启动；无在线改密 |
| 多浏览器实例 | 固定 Cookie 不按端口隔离，不建议同一 hostname 同时运行多个独立实例 |
| 配置导入 | 依赖 `kevinburke/ssh_config` 的模式匹配：`?` 会匹配零或一个字符（OpenSSH 要求恰好一个），极少数通配写法结果可能与 OpenSSH 不同；超过 8 KiB 的单行指令拒绝 |
| 快捷键 | 浏览器保留的组合键（如 Ctrl/⌘+W、⌘+T）页面无法接管 |

## 工程边界

- `cmd/sshworkbench` 只处理命令行；`bootstrap` 组装依赖（`Compose`）、监听、控制通道与退出。
- `httpapi` 负责会话边界、生成 DTO、参数与错误映射；不直接操作数据库或 SSH client。
- `hosts` 管配置；`connections` 管目标、信任与异步连接尝试；`launch` 编排终端/隧道的建立；`terminals` 管会话与有界流；`files`/`textdoc`/`localdocs` 管文件语义；`tunnels`、`snippets`、`workspaces`、`credentials`/`vault`、`sshconfig`/`imports` 各自独立。
- `adapters/sqlite`、`adapters/sshtransport`、`adapters/platform` 承担具体实现。
- 前端终端实例、socket、解析 offset 和 dispose 在 controller 中；React 只管理布局与状态，不接管字节流；广播通过各终端 controller 的写入租约发送。
- `api/openapi.json` 是 REST 类型来源；生成文件不要手改。
- `web/e2e` 与 `tests/` 使用内存 SFTP + SSH 协议夹具与回环 echo 服务，不运行用户机器上的任意 shell 命令，被测服务使用临时 HOME。
