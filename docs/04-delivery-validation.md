# 实施顺序与验收门槛

下面是原始实施计划，不是已完成的测试报告。当前实现见 `docs/05-current-implementation.md`，已执行验证与未执行矩阵见 `docs/06-validation.md`。里程碑没有被估算为确定交付日期。

## 1. 先验证意义，再扩大范围

### M0：风险验证切片

交付：单一主机配置、真实 host-key 验证、SSH PTY、二进制 WS、xterm、基础 SFTP 上传、可观察的目录选择。只做足够测试的简单界面，不先铺全部菜单。

门槛：

- 在同一台机器、同一输入法、同一 SSH 主机上与旧工程、Keyway/Termix 对照，记录实际构建版本和复现步骤。
- 中文首次输入、连续组合输入、切换标签再输入无丢字、重复或错误抢键。
- 按每个字节切分中文和控制序列时无乱码；慢浏览器不会让服务端无限涨内存。
- 拖入文件的远端目标始终可见；没有 cwd 信息时不假装知道当前目录。
- 首连未知密钥确认、密钥变更阻断、非法 Origin 拒绝都真实生效。

若这条链路相对现有方案没有改善，先修问题或重新评估复用，不继续增加协议来制造“功能很多”的假进展。

### M1：安全与工程底座

交付：模块边界、OpenAPI/WS 契约、SQLite 迁移、凭据接口、本机 bootstrap、日志脱敏、CI 基础、本机安全启动与退出。

门槛：业务单测不依赖 HTTP server 或 Wails；HTTP 层不能直连 SSH/SQL；错误码稳定；未认证、跨站、重放 bootstrap 都失败。

### M2：可日用的 SSH 工作区

交付：主机管理、声明子集的配置导入、密码/密钥/交互认证/agent、单级跳板、标签与四分屏、主题、键位、退出状态、同页短断恢复。

门槛：快速打开关闭、切换主题和布局不会重连或双重绑定；认证取消和失败不泄漏 goroutine；页面刷新与后端重启的恢复边界明确显示。

### M3：文件与编辑闭环

交付：SFTP 操作、上传/下载队列、取消与重试、目录跟随、拖拽、文本编辑、保存冲突、浏览器新窗口、本机 CLI 单文件能力。

门槛：大文件不全量进内存；上传时终端仍可交互；关闭标签不丢任务；文件名、换行、BOM 与权限不被静默改变；存量远端变更不被无提示覆盖。

### M4：首版完整化与发布

交付：`-L` 隧道、命令片段与整条命令广播、远程登录+TLS、跨平台包、导入导出文档和兼容性报告。

门槛：真实三平台验收、凭据/会话安全测试通过，功能表没有“看起来已做、实际静默降级”的项目。远程模式达不到安全门槛就不能以可用功能发布。

不把具体人日当作承诺：输入法、Windows agent/IPC、SFTP 服务端差异和真实系统验证都是计划风险，应在 M0/M1 后重新估算。

## 2. 中文与终端测试矩阵

所有正式支持声明必须带 OS、浏览器、输入法、远端 shell 和依赖版本。Playwright 的合成 composition 事件不能替代真实系统输入法测试。

| 层 | 必测样例 | 验证方式 |
| --- | --- | --- |
| 输入法 | 首次聚焦中文、拼音候选、空格选词、数字选词、Enter 确认、Esc 取消、Shift 中英切换、长句、切标签后输入 | 真机人工记录；合成事件只做回归补充 |
| macOS | 系统拼音、Rime；Chrome/Firefox；Cmd/Option 与组合输入 | 真机 |
| Windows | 微软拼音；Edge/Chrome/Firefox；Ctrl/Alt 快捷键 | 真机 |
| Linux | Fcitx5/Rime 或 IBus；Chrome/Firefox；输入法切换 | 真机 |
| 字节流 | 中文每个字节位置拆包、emoji 四字节拆包、组合字符、非法 UTF-8、截断 ANSI/OSC | Go/TS 单测和协议集成 |
| 程序 | Bash/Zsh、Vim、less、top、tmux、密码提示、交互式认证 | SSH 集成 + 真机 |
| 宽度/布局 | 中英混排、全角标点、emoji、组合音标、窄窗、100/125/150/200% 缩放 | 渲染/截图与人工核对 |
| 字体/渲染 | 字体延迟加载、WebGL 不可用、WebGL context 丢失、DOM 回退 | 浏览器测试 |
| 生命周期 | StrictMode 重挂、标签隐藏显示、分屏 resize、旧 socket 回调、长粘贴后断线 | 单测 + E2E |

正式 V1 目标为桌面 Chrome/Edge/Firefox 的经验证版本。Safari 先列预览兼容，只有真机 IME 与布局矩阵通过后才升级为正式支持；不以“都是浏览器”推断一致性。手机暂不承诺。

GBK 等旧编码终端不列首版支持。测试应验证它被明确诊断而非错误地“自动修复”；非 UTF-8 文件名的破坏性操作应阻止。

## 3. 网络与生命周期测试

- 连接中取消、认证中取消、用户拒绝未知密钥、跳板认证失败、服务端不提供 SFTP。
- SSH 连接断开、WebSocket 断开、丢 ACK、迟到 ACK、重复 frame、断线期间达到缓存上限、超过保留时间。
- 同页重连不重复输出或输入；整页刷新不伪装原屏恢复；第二窗口不能同时成为写入方。
- 终端关闭不会误关其他终端、任务或隧道；应用退出能解除阻塞读并限时释放资源。
- 上传/下载并发时操作终端；上传源页面关闭要进入 interrupted，而不是永远显示 running。
- tunnel 端口占用、目标拒绝、停止时已有连接、重新启动、进程退出；默认不能 bind 到 `0.0.0.0`。
- 三类“local”分别测试：浏览器所在机器、Go 所在机器、SSH 目标机；不混淆隧道、文件或 agent 所在机器。

## 4. 文件安全与正确性

- 中文、空格、引号、换行、长文件名；Linux/Windows 后端的远端路径一致性。
- 大小为 0、超过编辑上限、超过上传配额、超过目录深度/文件数量的输入。
- `..`、绝对路径、盘符、混合分隔符、符号链接、上传覆盖和跨目录 rename。
- 不支持原子 rename、无写权限、磁盘满、读取后远端被修改、保存中断、临时文件清理。
- 编辑保留 BOM/换行与权限；多个窗口保存不得无提示覆盖。
- 取消一项任务不应取消其他项；重复点击创建/取消具备去重；重启恢复任务状态而非假装续传。
- 下载 Content-Disposition 无 header 注入，浏览器下载不以文件大小线性增加 JS 内存。

## 5. 安全门槛

| 威胁/错误配置 | 预期结果 |
| --- | --- |
| 外部网页访问本机 API / WebSocket | Host、Origin、会话和 CSRF 检查拒绝 |
| bootstrap 超时、重用或被写入 query | 拒绝；不存在长效 URL bearer token |
| 非 loopback + 无登录/TLS | 服务拒绝启动 |
| 伪造 Forwarded headers | 未配置受信任反代时无效 |
| 未知 host key / host key 变更 / known_hosts 损坏 | 分别显式确认、阻断、失败关闭 |
| 日志、崩溃诊断、导出配置 | 不包含密码、私钥、主密码、bootstrap 和终端逐键内容 |
| 注销、锁定、改密、过期 | 已有 WS/SSH/隧道按策略回收，而不只是下次 HTTP 失败 |
| 任意本机路径 / 配置中的执行指令 | 未授权拒绝，禁止自动执行 |
| 终端 OSC / 链接 / 文件名 HTML | 不触发本机命令、任意 URL、自动剪贴板写入或 HTML 注入 |
| 超大 WS frame / 慢消费者 / 任务洪泛 | 有界拒绝或背压，不产生无限队列 |

单用户身份意味着它有被授权目标的 shell 权限，不把“可以 SSH 到目标”误称为沙箱。依赖更新还要检查 SSH/WebSocket/前端渲染相关安全公告；已有测试不等于永久安全。

## 6. 性能与资源目标

这些是初始预算，不是已测数据；测试报告必须记录机器、浏览器、网络与版本。

- 8 个终端、2 个并发传输作为首版基本负载；每会话与全局缓存都有限额。
- 连续输出 100 MiB 时可暂停/关闭，内存不随累计输出线性增长；浏览器 scrollback 有上限。
- 持续创建/关闭 100 次会话后，goroutine、文件描述符和监听端口回到可解释的基线范围。
- 上传/下载 1 GiB 文件使用流式处理，内存不出现同量级增长；传输与终端的互相影响要实测。
- 快速分屏和缩放不输出 0×0 resize，不重复创建 SSH；浏览器后台降速也能触发有效背压。

在没有固定硬件和网络基线前，不承诺“零延迟”“多少 MB/s”或与原生终端完全相同性能。

## 7. 自动化与发布

实现后再建立相应检查，不在纯文档阶段伪造测试结果：

- Go：单测、协议集成、race、vet；SSH/SFTP fixture 使用受控测试服务，不连接个人生产服务器。
- 前端：类型检查、Vitest、Playwright；真实 IME 人工矩阵单独记录，不混成 E2E 已覆盖。
- 契约：OpenAPI/WS 消息的兼容性、生成文件漂移、非法输入与权限测试。
- 构建：锁定依赖、可复现的前端产物、三平台构建与实际启动，签名/校验和与第三方声明。
- 发布说明列明 UTF-8、浏览器版本、目录跟随支持范围、远程隧道位置和恢复边界。

Definition of Done：功能合同可逐项演示，关键边界有测试，真机中文矩阵有记录，安全失败场景能解释，遗留限制如实写出。不能用漂亮截图替代这些结果。
