# 第一版产品范围与工作流

本文是明确的建议范围，不是把功能菜单交回用户选择。它描述目标，不是实现状态；当前实现与未验收项见 `05-current-implementation.md`。

## 1. 产品定位

面向一个人在自己的电脑上管理多台 SSH 主机，核心闭环是：

**找到主机 → 验证身份并连接 → 终端操作 → 同步查看文件 → 上传/编辑 → 观察任务结果。**

远程访问同一 Go 服务是可选部署模式，不是多用户堡垒机。首版不追求 MobaXterm 的协议数量。

## 2. V1 功能合同

| 模块 | 必须交付 | 不作首版承诺 |
| --- | --- | --- |
| 主机 | 分组、收藏、搜索、最近使用、连接设置、配置导入诊断 | 云同步、组织权限、全部桌面客户端配置格式 |
| SSH | 密码、私钥、加密私钥、keyboard-interactive、系统 agent、单级 ProxyJump | 任意 ProxyCommand、Match exec、GSSAPI、完整 OpenSSH 等价行为 |
| 终端 | 标签、拖动排序、最多四分屏、搜索、可配置键位、明确退出状态 | 任意嵌套停靠、录制回放、跨设备共享会话 |
| 连接恢复 | 页面仍存活时的短暂 WebSocket 重连；显示失败原因 | SSH 连接断掉后恢复原 shell；后端重启后恢复原进程 |
| 文件 | SFTP 列表、路径导航、隐藏文件开关、排序、新建目录、重命名、删除、基础 chmod | FTP/SMB/WebDAV、跨主机同步、SCP 回退 |
| 传输 | 多文件/目录上传、下载、文件夹打包下载、进度、取消、失败重试 | 断点续传、后台关闭浏览器后继续读取浏览器文件 |
| 编辑器 | UTF-8/BOM、保留换行风格、语法高亮、保存、保存冲突提示、新窗口 | 二进制编辑、自动猜测 GBK、任意大小文本全量加载 |
| 隧道 | 本地 TCP 转发 `-L`，启动/停止/状态/端口占用提示 | `-R`、`-D`、自动公开监听、UDP |
| 多终端操作 | 命令片段、显式目标清单、整条命令广播 | 逐键广播、自动解析所有 shell 危险命令、自动重试命令 |
| 本机集成 | 自动开浏览器、本机 CLI 指定文件编辑、浏览器上传下载 | 系统全盘文件管理、托盘常驻、剪贴板文件对象、系统文件关联注册 |

### OpenSSH 配置导入的边界

- 支持可枚举 `Host`、`HostName`、`User`、`Port`、`IdentityFile`、`IdentitiesOnly`、系统 agent 选择及单级 `ProxyJump` 的已声明子集。
- 对通配 Host 与配置顺序遵守明确测试的匹配规则；通配模式不会凭空枚举主机。
- 本机 `Include` 只读取获准范围内文件，有循环与深度上限；远程上传导入不允许沿 Include 读取服务端任意路径。
- 不执行 `ProxyCommand`、`LocalCommand`、`Match exec`。影响认证或路由的未支持指令必须提示，不能默默当作支持。
- 导入是读取快照，不自动修改原始 `~/.ssh/config`；系统 known_hosts 只读参考，新增信任写入应用自己的存储。

## 3. 界面方案

```text
┌──────────────────────────────────────────────────────────────┐
│ 工作区名称   快速连接/命令搜索          本机/远程 · 锁定 · 设置 │
├──────────────┬───────────────────────────────────────────────┤
│ 主机搜索     │ prod-01 ×   staging ×   +                     │
│ 收藏 / 分组  ├──────────────────────────────────┬────────────┤
│ 主机树       │ 终端 / 分屏                       │ SFTP 文件  │
│              │                                  │ 路径面包屑 │
│              │                                  │ 目录列表   │
│              │                                  │ 编辑/上传  │
├──────────────┴──────────────────────────────────┴────────────┤
│ 传输任务 2    隧道 1    当前主机 · 编码 · 目录同步状态         │
└──────────────────────────────────────────────────────────────┘
```

- 左侧固定主机导航，中间给终端最大空间，右侧为当前终端对应的可折叠文件面板；编辑器可占用中心区域或新窗口。
- 传输和隧道在底部抽屉，不塞进每个终端组件；关闭终端标签不会悄悄终止独立任务。
- 统一颜色、间距、圆角、字体和焦点 tokens；先做一套完整深色与浅色主题，不先做主题商城和复杂动效。
- 文件名、状态和错误使用中文界面文案；SSH/Go 内部错误码不直接作为用户提示。
- 高风险操作必须显示完整目标主机、端口、目录或广播目标数量；生产主机支持醒目标记。
- 键盘导航、焦点可见、可读对比度、200% 缩放属于验收项；后台任务进度更新不得抢走终端输入焦点。
- 小窗口收起侧栏和文件面板。首版支持桌面浏览器，不把手机虚拟键盘体验列为已保证能力。

## 4. 四条核心流程

### 4.1 连接与身份校验

选择主机 → 显示解析后的地址与跳板 → 确认未知主机 SHA256 指纹 → 输入所需凭据 → 建立终端。

- 未知密钥必须由用户核对后接受；指纹变化默认阻断，不能只有一个轻率的“忽略并继续”。
- 跳板与最终主机各自验证身份，不能只验证跳板。
- 密码默认不保存；保存是明确选项；输入口令不会进日志、命令历史或 localStorage。
- 连接错误区分 DNS、超时、拒绝、认证失败、主机密钥冲突与服务端能力不支持。

### 4.2 拖文件进终端

拖入文件 → 预览“上传到 主机:/完整目录” → 确认冲突策略 → 加入传输队列 → 显示结果。

“当前目录”有三种状态：

| 状态 | 行为 |
| --- | --- |
| 当前 shell 最近报告目录 | 展示目录与更新时间，以其为默认上传目标；仍展示确认 |
| 文件面板手动选择目录 | 标明“文件面板目录，未与终端同步”，由用户确认 |
| 没有可用目录 | 打开目录选择，不自动假定为终端工作目录 |

目录跟随首版针对 Bash/Zsh，使用用户同意启用的 shell integration/OSC 7 报告。其他 shell 手动选择目录。不会自动修改远端 rc 文件，不通过向正在运行的 Vim、密码提示或交互程序塞入 `pwd` 来探测。

OSC 数据是远端提供的提示，可能过期或被伪造。只用作当前连接的目录候选，不用它执行本机命令、打开本机路径或自动创建信任关系。远端再 `ssh` 到别的主机时，未能匹配会话目标的目录报告不得用于自动跟随。

上传完成后可以“复制远端路径”，但不自动在终端执行上传的文件。

### 4.3 编辑与保存

SFTP 打开文本 → 记录读取版本 → 编辑 → 保存前检查远端变化 → 临时文件写入 → 支持时原子替换 → 更新列表。

- 首版在线编辑上限拟设为 2 MiB；更大文件提供下载，不让 Monaco 和浏览器一次性吞入大文件。
- 保存前比较内容摘要和 stat 元信息；变化则提示重新加载、对比或另存，不直接覆盖。
- SFTP 普通 stat/write 不提供跨客户端的严格 compare-and-swap。这里是尽力检测冲突，不承诺消除远端并发写入的所有竞争窗口。
- 支持服务端原子 rename 扩展时使用同目录临时文件替换，并保留权限；不支持时明确提示降级策略，不宣称所有服务器都能原子保存。
- 编辑窗口通过同源认证访问不透明文档 ID，不把私钥、密码或文件内容放进 URL。
- `BroadcastChannel` 只提示另一个窗口文件已变化；真正保存判定仍在服务端。

### 4.4 隧道与命令广播

隧道是独立对象，不附属于某个终端组件。关闭面板不停止隧道；停止操作与进程退出才清理监听和 SSH 资源。

整条命令广播使用独立输入区：选择目标 → 预览完整命令与主机列表 → 二次确认 → 各发送一次。普通终端键盘、密码、剪贴板与上传操作不自动广播。

广播不声称能识别所有 shell 的就绪或密码状态。用户必须确认目标是可接收该命令的 shell；网络断线后显示未发送/结果不确定，不重放已有发送。危险命令关键词提示只能是辅助，不能当作安全证明。

## 5. 浏览器替代方案的真实限制

### 浏览器窗口不是桌面窗口

用户点击按钮时打开编辑器，以避免被弹窗策略拦截；被拦截时提供普通链接。浏览器保留自己的标签页和快捷键，不能保证接管 `Cmd/Ctrl+W` 等保留键。

### 本机文件来自明确授权，不来自任意路径 API

拟议 CLI：`sshworkbench edit /absolute/path/to/file`。

CLI 经本机、仅当前 OS 用户可用的控制通道注册这个文件，服务端生成有时效的文档授权，再打开浏览器。Web API 不能把任意请求参数当成本机文件路径。首版远程部署模式关闭这类本机文件编辑能力。

普通上传下载使用标准浏览器 File/HTTP 接口；不依赖 File System Access API 才能完成基本工作流。新窗口、CLI 与本机桥接是有界能力，不重新造一个 Wails 容器。

### 隧道开在哪台机器

```text
本机模式：浏览器 A → Go A → SSH B
          -L 监听 A 的 127.0.0.1

远程模式：浏览器 A → HTTPS → Go C → SSH B
          -L 监听 C 的 127.0.0.1，不是 A
```

界面必须显示 Go 所在机器与监听地址。浏览器不能凭空替远端访问者建立其电脑上的 TCP 监听；首版不承诺“服务器托管也能在浏览器用户的 localhost 上转发”。

### 刷新不是网络短断

同一页面中短暂断线可以保留 xterm 状态并续接；整页刷新会丢失终端解析器和屏幕状态。首版恢复工作区布局，但不声称从任意一段环形输出缓存就能重建 Vim/tmux 全屏状态。

刷新后显示旧会话保留期限与新建/关闭入口，不静默把新 SSH shell 伪装成原会话。用户需要远端进程持久化时可自行使用 tmux；应用不自动安装或偷偷套用 tmux。

## 6. 排除与后续

| 能力 | 决定 | 原因 |
| --- | --- | --- |
| RDP / VNC | 不进 V1；V2 单独论证 | 协议、画面、键盘、剪贴板与网关扩大测试面 |
| 串口 / Telnet | 不进 V1 | 不属于 SSH/SFTP 主链路，浏览器及系统能力边界不同 |
| X11 转发 | 不进路线承诺 | 不把本地 X Server 和桌面转发重新打包进 Web 产品 |
| 本地 shell | V1.1 | PTY/ConPTY、权限和输入法要独立验证 |
| 逐键同步输入 | V1.1 | 需要明显的广播态、快速退出、IME 与密码防误发设计 |
| `-D` / `-R` | V1.1 | 先把一种转发的生命周期与监听权限做对 |
| AI / MCP / 插件市场 | 不为其预留首版框架 | 与当前问题无关，不以抽象未来需求扩大工程 |
